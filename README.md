## Technology

The site uses static HTML, CSS, and JavaScript only.

This keeps it:

- fast
- easy to host
- easy to review
- accessible without a build system
- reliable on GitHub Pages

## GitHub Pages setup

```text
Branch: main
Directory: repository root
```

## Maintenance checklist

When a project changes:

1. update its repository README
2. update the GitHub profile README
3. update the corresponding portfolio case study
4. check that numbers, status, terminology, and limitations match
5. update the sitemap when adding a new page
6. verify links and mobile layout
