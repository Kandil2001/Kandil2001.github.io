# Ahmed Kandil Portfolio Website

Personal portfolio website for CFD, numerical simulation, scientific computing, and HPC projects.

Website: https://kandil2001.github.io

## Main message

This site is meant to show Ahmed as a CFD-focused engineer who can:

- build small CFD solvers from first principles,
- validate results instead of only showing pretty plots,
- compare MATLAB, Python, C, C++, MPI, OpenMP, and CUDA workflows,
- communicate engineering limits clearly.

## Main files

- `index.html` — homepage
- `style.css` — full responsive styling
- `script.js` — mobile navigation, analytics, and visit counter
- `projects/` — individual project pages
- `sitemap.xml` — pages exposed to search engines

## Recommended GitHub Pages setup

Publish from the `main` branch and repository root.

## CV

The CV button is currently not shown because no CV PDF is stored in the website repository yet. To add it later, upload your PDF as:

```text
assets/Ahmed_Kandil_CV.pdf
```

Then add a button linking to that path in `index.html`.
