LBM learning project · C++

D2Q9 LBM Channel Flow in C++

A small lattice Boltzmann Method project for 2D Poiseuille flow. The goal is not to make the most advanced solver, but to understand the collide–stream cycle and verify the result against the analytical parabolic profile.

Problem

Poiseuille flow is a good first LBM case because the expected velocity profile is known. That makes it easier to see whether the implementation is physically reasonable before moving to harder CFD cases.

My contribution

  • Implemented a minimal D2Q9 lattice Boltzmann solver in C++.
  • Used body-force-driven channel flow with top and bottom bounce-back walls.
  • Kept the code divided but simple: constants/helpers in include/ and solver logic in src/.
  • Exported centreline velocity, velocity field, convergence history, and run information.
  • Added a Python plotting script to compare LBM output with the analytical profile.

Why it belongs on the portfolio

This project shows learning-by-building. It is small, readable, and honest. It also supports the wider CFD portfolio because LBM can later become a second numerical method beside finite-volume pressure-correction solvers.
