LBM validation project · C++17

D2Q9 Lattice Boltzmann Channel Flow

A compact C++17 implementation of the lattice Boltzmann method for two-dimensional Poiseuille flow, built to validate the numerical velocity profile against the analytical parabolic solution.

Problem

Poiseuille flow is a useful first LBM validation case because the expected velocity profile is known analytically. This makes it possible to check whether the implementation is physically reasonable before moving to harder CFD cases.

Numerical method

Lattice

D2Q9 lattice Boltzmann model with a BGK single-relaxation-time collision step.

Boundary conditions

Bounce-back treatment at the upper and lower walls, with periodic streamwise direction.

Driving force

A small constant body force drives the channel flow and produces the analytical parabolic profile.

Validation run

The included validation figures are generated with nx = 160, ny = 50, steps = 20000, tau = 0.8, forceX = 1e-6, and saveEvery = 200.

My contribution

  • Implemented the D2Q9 LBM collide-stream workflow in C++17.
  • Added body-force-driven channel flow, bounce-back wall handling, and periodic streamwise behavior.
  • Exported centerline profile, velocity field, convergence history, and run information.
  • Added Python post-processing to compare numerical output with the analytical profile.
  • Kept the repository small and readable so the numerical method remains easy to inspect and extend.

Limitations and next steps

  • The project uses a single-relaxation-time BGK model and one simple channel-flow validation case.
  • Useful next steps include grid convergence, Reynolds-number variation, OpenMP parallelization, and extension to a lid-driven cavity or obstacle-flow LBM case.
