Problem

The lid-driven cavity benchmark is used here as a controlled CFD test case for pressure–velocity coupling, mesh sensitivity, convection schemes, convergence behaviour, and validation against Ghia et al. centreline velocity data.

Why this version matters

The MATLAB solver is useful for rapid development and comparison. This C++ version keeps the same physical benchmark idea but moves the implementation into a lower-level compiled language, making it a better baseline for future OpenMP, MPI, and CUDA acceleration.

My contribution

  • Reimplemented the pressure-correction workflow in serial C++17.
  • Kept the study structure aligned with the MATLAB benchmark for fair comparison.
  • Added CSV export for fields, residual histories, and study summaries.
  • Used Python post-processing to generate contours, streamlines, Ghia validation plots, and study-level comparisons.

Numerical methodology

Flow model

Two-dimensional incompressible Navier–Stokes equations with a moving lid and no-slip cavity walls.

Pressure coupling

Pseudo-transient pressure-correction algorithm on a structured collocated Cartesian grid.

Study matrix

N = 32, 64, 128; Re = 100, 400, 1000; upwind/central; RBGS/RBSOR; serial C++ implementation.

Representative results

Results and interpretation

  • 22 of the 36 cases met the selected Ghia centreline-error limits.
  • All N = 128 cases met the selected validation thresholds.
  • The refined-grid central-difference cases gave the strongest validation behaviour.
  • RBSOR produced nearly the same validation error as RBGS while reducing pressure-solver cost.
  • The full uploaded study took about 4.83 hours on the machine used to generate the results.

Current direction

This repository is the serial C++ baseline in a larger lid-driven cavity comparison study. The next step is to compare it with OpenMP, MPI, CUDA, Python, C, and OpenFOAM implementations using the same benchmark specification and result layout.

Limitations

The solver is an educational and portfolio solver, not a production CFD package. It uses a collocated grid without Rhie–Chow interpolation and an iterative pressure solver without multigrid acceleration. The convergence strategy and pressure–velocity treatment are still the main areas for improvement.
