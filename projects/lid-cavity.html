CFD Solver Development

MATLAB Lid-Driven Cavity Solver

A two-dimensional incompressible-flow solver using the SIMPLE algorithm and staggered-grid discretization.

Tools

MATLAB, numerical methods, plotting

Methods

SIMPLE, finite volume, staggered grid

Outputs

Residuals, contours, centerline profiles

Project overview

This project implements a CFD benchmark for incompressible flow in a square lid-driven cavity.

What to show here

  • Velocity magnitude contour
  • Streamlines and vorticity
  • Residual convergence history
  • Centerline velocity validation against reference data
  • Comparison between iterative and vectorized implementations
