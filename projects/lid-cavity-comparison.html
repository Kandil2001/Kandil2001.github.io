Why this is the strongest website project

This project connects the parts recruiters usually care about: CFD understanding, numerical methods, readable code, compiled-code development, parallel programming, and honest comparison of results. It is stronger than showing only one solver because it explains how the same problem changes when the implementation changes.

Benchmark idea

The physical problem is kept as consistent as possible. Each implementation exports comparable CSV files so the comparison scripts can match cases by mesh size, Reynolds number, convection scheme, and pressure solver instead of by run order.

What I would highlight in interviews

  • Started from a readable MATLAB reference before moving to C++, C, Python, and parallel versions.
  • Kept a shared result structure so outputs can be compared fairly.
  • Separated smoke, quick, medium, and full run modes for practical testing.
  • Documented MPI as case-level parallelism instead of pretending it is domain decomposition.
  • Kept CUDA as a GPU path but clearly marked that it requires an NVIDIA GPU and CUDA toolkit.

Suggested next improvements

  • Add final benchmark plots after the full run finishes.
  • Add one clear summary table: runtime, validation error, and comments for each implementation.
  • Add a short “What I learned” section to make the repository more human.
  • Add OpenFOAM and LBM later as separate follow-up projects, not mixed too early into the main benchmark.
