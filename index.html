Reference CFD Solver

MATLAB Lid-Driven Cavity Solver

Developed the reference version of a two-dimensional incompressible-flow solver and automated a 72-case benchmark study across mesh sizes, Reynolds numbers, schemes, pressure solvers, and MATLAB implementations.

Result: 44 of 72 cases met the selected Ghia centreline-error limits. The remaining cases were kept and documented instead of hidden.

MATLAB · CFD · Pressure Correction · Validation

C++ CFD Baseline

C++ Lid-Driven Cavity Solver

Reimplemented the same benchmark in serial C++17 as a clean single-core baseline. This version is designed to make later OpenMP, MPI, CUDA, and OpenFOAM comparisons fair and easy to understand.

Result: 22 of 36 cases met the selected Ghia validation limits; all refined-grid cases passed the selected thresholds.

C++17 · CFD · CSV Export · Python Post-processing

High-Performance Computing

Distributed TSP Solver

Built a distributed-memory optimisation solver in C99 and MPI using parallel tempering, two-opt moves, precomputed distances, and coordinated replica exchanges.

Result: The tested Berlin52 configuration reported a 20.7× speedup and approximately 86% parallel efficiency on 24 cores.

C99 · MPI · HPC · Parallel Tempering

Computational Simulation

JuPedSim Evacuation Analysis

Created a configurable pedestrian-evacuation workflow using a real building geometry, manually defined exits, scenario-based assignments, and reproducible trajectory output.

Result: Built a repeatable framework for studying how spawn locations, exit choices, and movement parameters affect evacuation behaviour.

Python · JuPedSim · PedPy · Numba · SQLite
