Engineering approach

From physical assumptions to documented results.

A strong simulation project should make the full workflow clear: assumptions, setup, numerical method, validation, limitations, and next steps. This portfolio is structured around that idea.

Physics-led setup Each project starts from the physical problem before moving into software, code, or visualisation.
Reproducible workflow Projects are organised with run instructions, structured outputs, plots, and notes so the work can be checked and extended.
Transparent validation The portfolio includes reference comparisons, mesh effects, runtime behaviour, and limitations rather than only final plots.

LBM D2Q9 validation project

D2Q9 LBM Channel Flow in C++

A compact C++ lattice Boltzmann solver for 2D Poiseuille channel flow using D2Q9, BGK collision, bounce-back walls, periodic streamwise boundaries, and CSV output.

Current result: the numerical velocity profile is compared directly with the analytical parabolic Poiseuille solution and includes convergence-history output.

MPI high-performance computing

Distributed TSP Solver

A C99/MPI distributed-memory Traveling Salesman solver using parallel tempering, Metropolis acceptance, two-opt route updates, precomputed distances, and neighbour replica exchange.

Current result: the Berlin52 study reported 20.7× speedup on 24 cores, approximately 86% parallel efficiency, with scaling and runtime-breakdown plots.
