High-Performance Computing

Distributed TSP Solver

Developed a distributed-memory optimisation solver in C99 and MPI using parallel tempering, two-opt moves, precomputed distances, and coordinated replica exchanges.

Result: The tested Berlin52 configuration reported a 20.7× speedup and approximately 86% parallel efficiency on 24 cores.

C99 · MPI · HPC · Parallel Tempering

Built a configurable pedestrian-evacuation workflow using a real building geometry, manually defined exits, scenario-based assignments, and reproducible trajectory output.
